Conexión con GitHub
Tus pasos se guardan en un archivo data/pasos.json dentro de tu propio repositorio. El token se queda solo en este celular — nunca se envía a ningún otro lado más que a GitHub.
Si cambias de celular
Instala este mismo archivo HTML en el otro celular, entra a Config, pon el mismo usuario/repo y un token nuevo — va a descargar automáticamente todo tu historial desde GitHub.
